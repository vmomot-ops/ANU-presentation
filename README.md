# Університет імені Альфреда Нобеля — презентація (веб-версія)

Статичний сайт: одна сторінка `index.html` і папка `assets/` з графікою та анімацією «Планети». Збирання не потрібне — файли можна розміщувати як є.

## Структура

```
index.html        — сторінка: головна, постійне меню, 11 розділів
assets/           — логотипи, постери, мапа, анімація planet.mp4
.nojekyll         — вимикає обробку Jekyll на GitHub Pages
```

## Розміщення на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `anu-presentation`).
2. Завантажте в нього весь вміст цієї папки (Add file → Upload files), зберігаючи папку `assets/`.
3. Відкрийте Settings → Pages.
4. У розділі «Build and deployment» оберіть Source: «Deploy from a branch», гілку `main`, папку `/ (root)` і натисніть Save.
5. За хвилину-дві сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Корисне

- Пряме посилання на розділ: додайте до адреси `#numbers`, `#history`, `#mission`, `#program`, `#research`, `#civic`, `#social`, `#qualification`, `#international`, `#unique` або `#form`.
- Навігація під час показу: клавіші ← → (або PageUp / PageDown), кнопка «На весь екран» у меню.
- На великих екранах кожен розділ масштабується як слайд; на телефоні — звичайна прокрутка.
- Шрифти (Unbounded, Roboto) підвантажуються з Google Fonts, тому для коректного вигляду потрібен інтернет.
